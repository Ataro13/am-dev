## Шаг 1. Открыть проект Supabase

1. Откройте браузер и перейдите на https://supabase.com
2. Нажмите **Sign in** (вход) — войдите через GitHub или email.
3. После входа вы попадёте в список проектов (Dashboard). Если проект не открылся сам —
   нажмите на карточку проекта **am-dev-cabinet** (или как он называется).
4. Откроется панель проекта. Слева — вертикальное меню (SQL Editor, Table Editor,
   Authentication, Project Settings…).

> ⚠️ Если проекта нет в списке — нажмите **New project** и создайте заново
> (имя любое, регион Frankfurt, пароль БД придумайте и сохраните).

## Шаг 2. Выполнить схему базы (создать таблицы)

1. В левом меню нажмите **SQL Editor** (иконка `</>`).
2. Нажмите кнопку **New query** (создать новый запрос) — откроется редактор.
3. Откройте на компьютере файл `supabase/schema.sql` (папка проекта AM-DEV).
   Откройте его Блокнотом (ПКМ → «Открыть с помощью» → «Блокнот»),
   нажмите Ctrl+A (выделить всё), Ctrl+C (копировать).
4. Вернитесь в браузер, кликните в большой белый редактор и нажмите Ctrl+V (вставить).
5. Нажмите синюю/зелёную кнопку **Run** (внизу справа в редакторе).
6. Внизу появится зелёное сообщение **«Success. No rows returned»** — значит всё прошло.
   Если видите красный текст (ошибку) — скопируйте её и пришлите мне.

✅ После этого готово: созданы 4 таблицы (profiles, tasks, subscriptions, news) + правила доступа.

## Шаг 6. Как потом править данные (на будущее)

### 1. Задачи клиента
- Левое меню → **Table Editor** → таблица `tasks`.
- Кнопка **Insert row** — добавить задачу: `user_id` (взять id клиента из
  Authentication → Users), `title` (текст), `status` (`done` / `in progress` / `waiting`).
- **Сменить статус задачи** (сделано/в работе): клик по ячейке `status` →
  выпадающий список → выбрать `done` или `in progress` → **Save** (кнопка
  появится внизу таблицы). Или клик по всей строке → Edit → изменить → Save.
- Удалить задачу: галочка слева от строки → **Delete**.

### 2. Подписка клиента
- **Table Editor** → `subscriptions` → **Insert row**:
  - `user_id` — id клиента,
  - `plan` — название тарифа (например «Стандарт»),
  - `status` — `active`,
  - `started_at` / `expires_at` — даты (формат `2026-08-10`),
  - `price` — сумма в рублях (например `5000`).

### 3. Новости
- **Table Editor** → `news` → **Insert row**: `title` (заголовок), `body` (текст).

### 4. Данные клиента (имя, сайт, контакт)
- **Table Editor** → `profiles` → строка клиента → поля
  `display_name`, `site_url`, `contact`, `project_status`.
- Клик по ячейке → изменить → **Save**. Клик по строке → Edit → Save.

### 5. Сменить пароль клиента
- **Authentication** → **Users** → строка клиента → **…** (три точки)
  → **Reset password** — Supabase пришлёт клиенту письмо со ссылкой
  (клиент сам задаст новый пароль).
- Если нужно задать пароль **самим** (без письма) — используйте готовый
  скрипт `supabase/change_user.sql` (там же меняется и логин/email).
- ⚠️ Новый пароль передайте клиенту сами (в письме он не придёт, если вы
  создали его вручную).

### 6. Сменить логин (email) клиента
- Логин клиента — это его **email** (для входа). Если поменять email —
  клиент будет входить новым.
- Проще всего — готовый скрипт `supabase/change_user.sql`: открыть,
  скопировать целиком, вставить в **SQL Editor** → **Run**.
  (В файле вверху написано, какой email и пароль он проставит — поменяйте,
  если нужно.)
- Или вручную через SQL: **SQL Editor** → **New query**:
  ```sql
  update auth.users
  set email = 'новый@email.ru', email_confirmed_at = now()
  where id = '<id клиента из Authentication → Users>';
  ```
  ⚠️ Этот ручной способ подходит, только если email — обычная колонка.
  В новых версиях Supabase он может быть «generated» (тогда SQL Editor
  покажет ошибку «column "email" can only be updated to DEFAULT»).
  В этом случае просто используйте готовый скрипт `supabase/change_user.sql` —
  он сам определяет, что менять можно, а что нельзя.
  ⚠️ После смены email **обязательно** поправьте `username` в профиле
  (он используется для отображения логина в разделе «Мои данные»):
  - **Table Editor** → `profiles` → строка клиента → поле `username` →
    вписать новый логин (часть нового email до `@`) → **Save**.
- Новый email/логин передайте клиенту.
