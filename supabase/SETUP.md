# Личный кабинет AM.DEV — настройка (один раз)

Кабинет работает на **Supabase** — бесплатная облачная база + авторизация.
Никакого своего сервера не нужно: сайт остаётся статическим.

---

## Шаг 1. Создать проект Supabase

1. Зайдите на https://supabase.com и войдите (GitHub или email).
2. **New project**:
   - Organisation — любая (например, ваша).
   - Name — например `am-dev-cabinet`.
   - Database Password — придумайте и **сохраните** (понадобится только вам).
   - Region — ближайший к клиентам (например `Frankfurt (eu-central-1)`).
3. Дождитесь создания проекта (~1–2 минуты).

## Шаг 2. Выполнить схему базы

1. В панели проекта слева: **SQL Editor** → **New query**.
2. Откройте файл `supabase/schema.sql` из проекта, скопируйте его **целиком**.
3. Вставьте в редактор и нажмите **Run** (зелёная кнопка).
4. Убедитесь, что внизу «Success. No rows returned».

Этим создаются таблицы: профили клиентов, задачи, подписки, новости —
и правила доступа (клиент видит только свои данные).

## Шаг 3. Вставить ключи в код

1. В панели слева: **Project Settings** (шестерёнка) → **API**.
2. Скопируйте:
   - **Project URL** (вида `https://xxxx.supabase.co`)
   - **anon public** (длинная строка `eyJ...`)
3. Откройте `js/cabinet-config.js` и вставьте их:

```js
window.AM_CABINET = Object.assign(
  {
    SUPABASE_URL: "https://ВАШ-ПРОЕКТ.supabase.co",
    SUPABASE_ANON_KEY: "eyJ...",
    LOGIN_SUFFIX: "@amdev.local"
  },
  window.AM_CABINET || {}
);
```

4. Загрузите файлы на хостинг — кабинет заработает.

## Шаг 4. Создавать клиентов (для каждого нового клиента)

1. В панели слева: **Authentication** → **Users** → **Add user** → **Create new user**.
2. **Email**: **реальная почта клиента** (например `bela@yandex.ru`) —
   именно её клиент будет вводить при входе.
   *(Старый вариант `<логин>@amdev.local` тоже работает: клиент может ввести
   просто логин без `@` — суффикс `@amdev.local` код добавит сам.)*
3. **Password**: придумайте пароль — **именно его вы выдаёте клиенту**.
4. Нажмите **Create user**.

Профиль клиента (имя, сайт, контакт, статус проекта) заполняется автоматически
с логином. Дополните его:

- **Table Editor** → `profiles` → строка клиента → поля:
  - `display_name` — имя (показывается в приветствии и шапке кабинета),
  - `site_url` — сайт клиента,
  - `contact` — телефон/почта,
  - `project_status` — краткий статус проекта (показывается на главной кабинета).

## Шаг 5. Наполнить кабинет

- **Задачи** → `tasks`: `title` (текст задачи), `status` (`done` / `in progress` / `waiting`),
  `user_id` — возьмите `id` клиента из Authentication → Users.
- **Подписка** → `subscriptions`: одна строка на клиента.
  - Нет подписки → не создавайте строку (клиент увидит кнопку «Оформить подписку»
    с переходом на ваш Telegram).
  - Есть подписка → `status: active`, `plan` (тариф), `started_at`, `expires_at`, `price`.
- **Новости** → `news`: видны всем клиентам на главной кабинета (до 3 последних).

## Как это выглядит у клиента

1. Клиент открывает сайт → «Личный кабинет».
2. Вводит **email** (или логин) и **пароль** (выданные вами).
3. Видит: приветствие и статус проекта, задачи с прогрессом, статус подписки
   (или кнопку «Оформить подписку» → ваш Telegram), свои данные (в т.ч. email).

---

### Памятка
- Логин клиента — часть email до `@`. Вход: полный **email** (например
  `bela@yandex.ru`) или просто логин без `@` (код добавит суффикс
  `@amdev.local` из `js/cabinet-config.js` → `LOGIN_SUFFIX`).
- Пароль клиенту меняете там же: Authentication → Users → … → Reset password.
- Удаление клиента: Authentication → Users → … → Delete user
  (его данные в таблицах удалятся автоматически).
